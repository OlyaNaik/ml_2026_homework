Открывайте каждый блокнот из его папки: пути к `data` и `data_seminar` заданы относительно неё. Для запуска нужны `numpy`, `scipy`, `pandas`, `matplotlib`, `scikit-learn`, `joblib` и Jupyter.

В модуле 3 используются synthetic signal mixtures (синтетические смеси сигналов): для одного дефекта — linear interpolation (линейная интерполяция) между нормальным и дефектным сигналами, для сочетания дефектов — linear superposition (линейное наложение) составляющих. Числа 0–100 обозначают заданные mixing coefficients (коэффициенты смешивания), а не измеренный физический процент износа подшипника. Название synthetic signal mixtures описывает способ создания учебных примеров, а не отдельный стандартизованный алгоритм.
